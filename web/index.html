moonbit-pdf417 在线试用

下面的编解码全部由 MoonBit 编译成的 WebAssembly/JS 在你浏览器里跑， 没有服务端调用。源码：github.com/guangting0905/moonbit-pdf417

这一页在演示什么
  • 三种压缩模式：把载荷里的字母、长数字串、非 ASCII 字节分别用文本／数字／字节压缩，分段结果可以在「几何摘要」里看到。
  • 纠错：级别 0–8 对应 2–512 个 GF(929) 上的 Reed-Solomon 纠错码字。
  • 逆过程：解码页把矩阵解回字节，并给出「未精确匹配的符号字符数」与「实际修正的码字数」——两者分开，因为它们说明的是损伤程度与纠错余量两件不同的事。
  • 边界：解码器吃的是模块矩阵，不是照片。不做图像识别是有意的，见 README 的「已知限制」。
